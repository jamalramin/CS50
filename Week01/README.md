
# CS50 Week 1

## Description

This project is part of **CS50's Introduction to Computer Science**, Week 1.
It is written in the **C programming language** and demonstrates basic programming concepts such as variables, conditions, loops, functions, and user input.

## Getting Started

To compile the program, use:

```bash
make program
```

Then run it with:

```bash
./program
```

## What I Learned

* How to write programs in C
* How to use variables and data types
* How to use `if` and `else` statements
* How to create and use loops
* How to write functions
* How to compile and run C programs
