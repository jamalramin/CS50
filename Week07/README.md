# CS50 Week 7 — SQL

## Description

This week I learned the basics of SQL and how to work with databases using SQLite.

The exercises cover creating tables, inserting data, selecting records, filtering results, and using SQL queries to analyze data.

## What I Learned

* Creating and using SQLite databases
* `SELECT` queries
* `WHERE` conditions
* `ORDER BY`
* `GROUP BY`
* `JOIN`
* `INSERT`, `UPDATE`, and `DELETE`
* Using Python with SQLite
* Reading data from CSV files

## Files

The repository contains my solutions and exercises for Week 7 of CS50.

## How to Run

For SQLite exercises:

```bash
sqlite3 database.db
```

Then SQL queries can be executed directly in the SQLite shell.

For Python programs:

```bash
python program.py
```
