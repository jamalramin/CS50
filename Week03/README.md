## Algorithm

**An algorithm is solving a problem step by step.**

There are two ways for searching an element:

### 1. Linear Search

Linear search checks each element from beginning to end.

### 2. Binary Search

In this method, we look at the middle and eliminate half of the remaining possibilities.
